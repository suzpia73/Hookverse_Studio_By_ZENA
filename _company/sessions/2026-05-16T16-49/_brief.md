**원 명령:** CEO~ 아래 내용들 뭐가 문제이고 어떻게 하라는 거죠? 이해하기 쉽게 설명 부탁합니다~

❌ exit 9009

⚠️ Python 3 명령 실행 실패 (시도한 명령: python).
🔧 해결:
  1. https://www.python.org/downloads/ 에서 Python 3 설치 (Add Python to PATH 체크박스 필수!)
  2. 설치 후 안티그래비티/VS Code 완전 종료 → 재실행 (PATH 새로고침 필요)
  3. 또는 명령 팔레트 → "⚙️ 설정 열기" → connectAiLab.pythonPath 에 절대 경로 입력 (예: /usr/local/bin/python3 또는 C:\\Python311\\python.exe)
🔍 본인 PC 의 Python 경로 확인:
  - PowerShell: Get-Command python, python3, py
