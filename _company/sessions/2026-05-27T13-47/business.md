# 💼 현빈 — # [CEO 명령: 시스템 안정화를 위한 단계별 업무 수행]

## 1. 운영 원칙
시스템 부하 방지를 위해, 모든 업무는 한 번에 하나씩 순차적으로 진행한다. 이전 단계가 완료되기 전에는 다음 에이전트에게 업무를 넘기지 마라.

## 2. 작업 순서
1단계: [영숙(Researcher)] - 5부작 시리즈의 전체 테마와 핵심 소재 1개만 선정하여 텍스트로 보고하라. (도구 미사용 가능성 열어둠)
2단계: [작가(Writer)] - 1단계 결과물을 바탕으로, 8분 이상 수익화 가능한 5부작 상세 스토리라인을 텍스트로 보고하라.
3단계: [코다리(Designer)] - 2단계 내용을 바탕으로 영상의 전체적인 비주얼 컨셉만 서술하라.

## 3. 오류 대응 전략
도구 실행 시 오류가 발생하면, 무리하게 재시도하지 말고 즉시 **"도구 사용 불가: 추론 모드 전환"**이라고 짤막하게 공지한 뒤, 텍스트로만 답변을 이어나가라. 시스템 종료가 아닌 '업무 지속'이 최우선이다.

[지시] PayPal 매출을 분석하고 다음 액션 1개 제안.

💼 현빈: 사장님, PayPal Client ID 또는 Secret 이 비어있어 매출을 가져올 수 없어요.

📋 **해결 단계**:
1. `Cmd+Shift+P` → `Connect AI: 외부 연결`
2. 💰 PayPal 카드 → Client ID + Secret 입력
3. 저장 → 즉시 매출 분석 가능

📊 평가: 대기 — PayPal 자격증명 입력 후 재시도.
📝 다음 단계: 사장님이 PayPal Developer Dashboard 에서 Client ID/Secret 복사 → 외부 연결 패널 입력.
