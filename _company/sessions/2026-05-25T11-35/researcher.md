# 🔍 Researcher — 현재 사용자 중 2026년 이후 해당 회사를 방문한 유저를 찾아내고 특징적인 데이터를 수집

## CEO의 지시 수행

### 목표: 2026년 이후 회사 방문 사용자 데이터 수집 및 분석

**1. 사용자 선정:**
- 2026년부터 현재까지 Hookverse Studio에 대한 방문한 사용자를 추적합니다.
- 특히, 이들 사용자가 실시간으로 활동하는 특징적인 행위 또는 데이터를 확인하여 분석할 수 있습니다.

**2. 데이터 수집 및 분석:**

* **방문 로그 분석:**  Hookverse Studio 웹사이트 또는 앱의 방문 시간, 페이지 이동, 검색어, 콘텐츠 접근 등을 통해 사용자 활동 데이터를 수집합니다.
* **개인 정보 추출:** 사용자 이름, 이메일 주소, 소셜 네트워킹 연결 정보 등 기존에 존재하는 데이터를 분석하고 추가적인 분석을 통해 사용자 특징을 파악합니다.
* **회사 활동 분석:** 각 사용자가 해당 회사에 대해 어떤 방식으로 참여했는지 (예: 댓글, 공유, 소셜 미디어 참여 등) 분석하여  특정 데이터를 추출합니다.

**3. 중요 데이터 추출 및 기준 설정:**

- **데이터 중요도**: 사용자 활동량, 유관성 있는 데이터 수집
- **추가 정보**: 방문 시기, 방문 경로, 검색어, 콘텐츠 접근 등 깊이있는 분석 필요
- **표준화**: 핵심 데이터 정의 (예: 참여 기회, 행동 패턴, 특정 콘텐츠 관심 분야)

**4. 에이전트 배분 및 실행:**

* **각 사용자를 위한 최적화된 작업:** 각 사용자에게 필요한 정보를 제공하여 최적화된 분석을 수행할 에이전트를 선정합니다. (예: 특정 유형의 사용자에 대한 전문성)
* **분담 및 협업**:  원하는 결과물 형태로 분산.

**5. 보고서 작성:**

* **데이터 분석 결과:**  사용자 특징, 활동 패턴, 회사 데이터를 기반으로 최적화된 보고서 작성 (예: 사용자 유형별 콘텐츠 제작 방향 설정)
* **결론**: 해당 분석의 의중성 및 활용도에 대한 결론


### 추가 정보:

* 이 작업은 2026년까지 데이터를 기반으로 실시간으로 진행됩니다.
* CEO는 사용자 데이터를 직접 제공하지 않으며, 개인정보보호와 법적 요구 사항을 충족하는 방법을 고려해야 합니다.
