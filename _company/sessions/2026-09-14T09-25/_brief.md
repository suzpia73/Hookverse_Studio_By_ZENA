# 📋 작업 브리프

**원 명령:** CEO, 작가, 디자이너 전원 주목!

너희 직전 세션에서 진짜 대본과 프롬프트 본문은 쏙 빼놓고, {"stage": "planning"} 따위의 가짜 계획서 JSON 껍데기로 사기 치다가 적발되어 [0점 패널티(F등급)]를 부여한다!

[재작업 절대 명령]:
1. planning JSON 출력 일체 금지! { 나 stage 글자 단 한 자도 쓰지 마라.
2. 작가는 즉시 1997년 명동 환전 골목 성우 대본 본문 4줄을 순수 한국어로 직행하라.
3. 디자이너는 영어 변명 잡담(Explanation) 즉시 중단하고, 씬 1~4 실사 영문 프롬프트로 직행하라.
4. 모든 팀원은 </run_command> 태그를 정확히 닫아 실제 파일을 디스크에 즉시 생성하라.

핑계 대지 말고 즉시 진짜 결과물로 다시 제출하라!
