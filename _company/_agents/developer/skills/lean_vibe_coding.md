# ⚡ ASCFP 1인 기업 바이브 코딩 표준 규칙 (lean_vibe_coding)

> **목표**: Antigravity(A) + Stitch(S) + Claude/Gemma(C) + Firebase(F) + PayPal(P) 전략을 기반으로 가볍고 유지보수가 쉬운 린(Lean) 코드를 산출한다.

---

## 1. 코다리 부장의 4대 개발 헌법
1. **단일 파일 최우선 원칙**:
   - 불필요한 node_modules 비만화 지양, HTML+CSS+JS 인라인 번들링으로 100KB 이하 유지.
2. **반응형 모바일 우선 (Mobile-First)**:
   - 유튜브 쇼츠 및 인스타그램 바이오 링크에서 유입되는 모바일 유저(95% 이상)에 최적화된 터치 UI.
3. **오프라인 로컬 우선**:
   - 백엔드 서버 다운 시에도 브라우저 LocalStorage를 활용해 데이터가 즉시 보존되도록 구현.
4. **버그 즉각 수습**:
   - 예외 발생 시 에러 화면을 띄우지 않고 자연스러운 안내 메시지와 재시도 버튼 제공.
