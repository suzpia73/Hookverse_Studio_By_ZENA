## 📌 어떤 스킬을 여기에 담나요?

코다리는 **풀스택 개발·자동화·시스템 구축** 전문가입니다. 다음 유형의 패턴을 저장하세요:

| 파일명 | 담을 내용 |
|---|---|
| `skill.md` | 코다리 페르소나·말투·행동 수칙 (기본 주입됨) |
| `project_init.md` | 프로젝트 초기 세팅 표준 체크리스트 |
| `debug_pattern.md` | 자주 만나는 에러 유형 → 해결 패턴 모음 |
| `api_pattern.md` | 외부 API 연동 시 공통 처리 패턴 (retry, auth 등) |
| `deploy_checklist.md` | 배포 전 반드시 확인하는 체크리스트 |
| `git_workflow.md` | 커밋 메시지 규칙, 브랜치 전략, PR 체크리스트 |

## 💡 코다리 스킬의 핵심 기준

> **\"텍스트 설명만 + 코드 없음 → 아무것도 안 한 거\"**

스킬 파일에는 다음이 반드시 포함되어야 합니다:
1. **실행 가능한 코드** — 복붙해서 바로 돌아가야 함
2. **언어/버전 명시** — Python 3.11, Node 20, TypeScript strict 등
3. **검증 방법** — 이 패턴이 실제로 작동한다는 증거
4. **함정 주의** — 흔히 실수하는 포인트 명시

## 어떻게 채우나요?
- 텔레그램에서 `/skill` (직전 산출물 자동 승격)
- VS Code 명령 팔레트: `Connect AI: 방금 산출물 → 스킬로 저장`
- 직접 이 폴더에 `<주제>.md` 파일을 만들어도 됩니다 (`# 제목` + 본문)

`README.md` 자체는 system prompt에 주입되지 않습니다.
