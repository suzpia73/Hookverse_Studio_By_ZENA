# 🧭 CEO 스킬 라이브러리

_재사용 가능한 패턴 모음. `memory.md`는 모든 활동의 로그(append-only firehose),
이 폴더는 **검증된 패턴만 골라낸 것**입니다. 각 `*.md` 파일은 다음 호출 시
CEO의 system prompt에 자동 주입됩니다._

---

## 📌 어떤 스킬을 여기에 담나요?

CEO 에이전트는 **오케스트레이터** 역할입니다. 다음 유형의 패턴을 저장하세요:

| 파일명 | 담을 내용 |
|---|---|
| `decision_framework.md` | A/B 의사결정 시 사용하는 분석 프레임 |
| `agent_dispatch.md` | 어떤 상황에 어떤 에이전트를 호출하는지 패턴 |
| `weekly_review.md` | 주간 회고 포맷 및 KPI 체크 루틴 |
| `okr_template.md` | OKR 작성 형식 및 우선순위 기준 |
| `report_format.md` | 각 에이전트 보고서를 취합·요약하는 포맷 |

---

## ⚠️ CEO 스킬 주입 규칙

- CEO의 응답은 **반드시 JSON 형식**으로만 출력됩니다
- 스킬 파일은 JSON 출력 품질을 높이는 **판단 기준**과 **라우팅 패턴**에 집중하세요
- 절차적 지식(\"어떻게\")보다 전략적 판단(\"왜\", \"무엇을 먼저\")을 담는 것이 핵심

---

## 어떻게 채우나요?
- 텔레그램에서 `/skill` (직전 산출물 자동 승격)
- VS Code 명령 팔레트: `Connect AI: 방금 산출물 → 스킬로 저장`
- 직접 이 폴더에 `<주제>.md` 파일을 만들어도 됩니다 (`# 제목` + 본문)

`README.md` 자체는 system prompt에 주입되지 않습니다.
