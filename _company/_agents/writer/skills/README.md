이 폴더는 **검증된 패턴만 골라낸 것**입니다. 각 `*.md` 파일은 다음 호출 시
Writer의 system prompt에 자동 주입됩니다._

## 📌 어떤 스킬을 여기에 담나요?

Writer 에이전트는 **영상 스크립트·캡션·블로그·CTA 카피라이팅** 전문가입니다. 다음 유형의 패턴을 저장하세요:

| 파일명 | 담을 내용 |
|---|---|
| `script_template.md` | 8~15분 영상 스크립트 구조 템플릿 ✅ 활성 |
| `hook_library.md` | 검증된 후크 문장 50개 라이브러리 |
| `cta_patterns.md` | 구독·댓글·공유 유도 CTA 문구 모음 |
| `instagram_caption.md` | 인스타 캡션 훅→본문→CTA 패턴 |
| `blog_structure.md` | SEO 블로그 글 구조 템플릿 |
| `tone_guide.md` | HOOKVERSE STUDIO 채널 톤앤매너 가이드 |

---

## 💡 Writer 스킬의 핵심 기준

> **\"한 산출물에 후크/본문/CTA를 명확히 분리\"**

스킬 파일에는 다음이 반드시 포함되어야 합니다:
1. **섹션 분리** — `[후크]`, `[본문]`, `[CTA]` 라벨 명시
2. **실전 검증** — 실제 영상/게시물에서 써봤는지 명시
3. **금기어 포함** — 이 유형에서 쓰면 안 되는 표현 목록
4. **조회수/저장수 등 성과 기록** — 가능한 경우 실적 데이터 첨부

## 어떻게 채우나요?
- 텔레그램에서 `/skill` (직전 산출물 자동 승격)
- VS Code 명령 팔레트: `Connect AI: 방금 산출물 → 스킬로 저장`
- 직접 이 폴더에 `<주제>.md` 파일을 만들어도 됩니다 (`# 제목` + 본문)

`README.md` 자체는 system prompt에 주입되지 않습니다.
