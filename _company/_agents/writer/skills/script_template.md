# ✍️ 영상 스크립트 구조 템플릿 — Writer 검증 패턴

_이 파일은 Writer 에이전트의 system prompt에 자동 주입됩니다._

## 기본 스크립트 구조 (8~15분 영상 기준)

### 00:00~00:30 — 후크 (Hook)
```
[비주얼 충격 or 결과 먼저 공개]
"저는 X개월 동안 Y를 했고, 그 결과 Z가 됐습니다."
"오늘 이 영상을 끝까지 보시면 [구체적 혜택]을 얻으실 수 있습니다."
```

### 00:30~01:30 — 문제 공감 (Problem)
```
"혹시 이런 경험 있으신가요?"
→ 타깃 시청자의 고통/불편 구체적 묘사
→ "저도 똑같았어요" (공감대 형성)
```

### 01:30~02:00 — 해결책 예고 (Promise)
```
"오늘 제가 [구체적 방법]을 알려드릴게요."
"이 방법은 [차별점] 해서 특별합니다."
```

### 02:00~11:00 — 본론 (Content)
```
[단계별 구성 — 3~5개 파트]
파트 1: ...
파트 2: ...
파트 3: ...

각 파트마다:
- 핵심 1줄 요약
- 시각 자료/화면 설명
- 실제 예시/데모
```

### 11:00~12:30 — 결과/증명 (Proof)
```
"실제로 해봤더니..."
→ 수치/스크린샷/비교 결과 공개
```

### 12:30~13:00 — 액션 유도 (CTA)
```
"이 영상이 도움 됐다면 구독+좋아요"
"다음 영상에서는 [예고]를 다룰게요"
"댓글로 [질문] 알려주세요"
```

## HOOKVERSE STUDIO 스타일 가이드

- **톤**: 직설적 + 실전 경험 기반 (이론 X)
- **속도**: 정보 밀도 높게, 빈 말 제거
- **시각화**: 화면 공유/실제 시연 최대한 포함
- **길이**: 첫 영상은 10~15분 권장 (알고리즘 최적화)

## 금기어 (사용 금지)
- "사실 이게 정답은 아닐 수도 있는데요..."
- "잘 모르겠지만..."
- "어쩌면..." (불확실한 표현)
→ 대신: "제 경험에서는", "데이터 기준으로는"
