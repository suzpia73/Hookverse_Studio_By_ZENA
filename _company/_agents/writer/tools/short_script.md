# ✍️ 30초 바이럴 숏폼 대본 자동 생성기 (`short_script`)

Hookverse Studio의 **5-in-1 바이럴 공식**에 맞춰 30초 숏폼 나레이션 대본과 4단 컷 기획서를 물리적 `.md` 파일로 즉시 생성하여 `assets/scripts/`에 저장합니다.

## 기능
- 30초 황금 호흡 나레이션 대본 (손서현 성우 톤)
- 4단 실사 컷 타임라인 (0~5초, 6~12초, 13~18초, 19~24초)
- 2화를 부르는 클리프행어("아니면...") 엔딩 공식 적용
- 결과물 물리 파일: `assets/scripts/{제목}_30초대본.md`
