# 🎬 유튜브 후크 작성 패턴 — 레오 검증 패턴

_이 파일은 레오(YouTube) 에이전트의 system prompt에 자동 주입됩니다._

## 검증된 후크 공식 (조회수 높은 영상 기반)

### 공식 1: 숫자 + 결과
```
"X일 만에 Y가 달라졌습니다"
"X원으로 Y를 만들었습니다"
"X개 중 1개만 살아남았습니다"
```

### 공식 2: 역설/반전
```
"돈 쓰지 말고 이걸 하세요"
"구독자 0명인데 수익이 났습니다"
"실패했는데 오히려 더 잘됐습니다"
```

### 공식 3: 공개/폭로
```
"아무도 알려주지 않는 X의 진실"
"X년 동안 숨겨온 비밀"
"업계 사람들이 싫어하는 영상"
```

### 공식 4: 도전/실험
```
"AI 직원 X명 고용해봤습니다"
"X일 동안 Y만 했더니..."
"전문가들이 말리는 걸 해봤습니다"
```

## HOOKVERSE STUDIO 채널 정체성에 맞는 후크

> 채널: AI 에이전트 스튜디오 구축 과정 + 실전 콘텐츠
> 타깃: AI에 관심있는 1인 크리에이터·소자본 창업자

### 추천 후크 방향
- "월급 0원으로 AI 직원 N명 고용했습니다" ← 이미 검증됨 (41K 조회)
- "AI로 혼자 회사 차린 현실"
- "AI 에이전트가 진짜 일하는 모습 공개"
- "N원으로 자동화 시스템 만든 과정"

## 제목 작성 규칙
1. **숫자 포함** — 구체적일수록 클릭률 ↑
2. **결과 먼저** — 과정보다 결과를 앞에
3. **50자 내외** — 모바일 잘림 방지
4. **키워드 포함** — "AI", "자동화", "무료", "0원"
