## 📌 어떤 스킬을 여기에 담나요?

레오(YouTube)는 **영상 기획·후크·썸네일 브리프·채널 전략** 전문가입니다. 다음 유형의 패턴을 저장하세요:

| 파일명 | 담을 내용 |
|---|---|
| `content_hook_pattern.md` | 조회수 높은 후크 공식 4가지 ✅ 활성 |
| `thumbnail_brief.md` | 클릭률 높은 썸네일 기획 브리프 템플릿 |
| `video_plan_template.md` | 영상 기획서 표준 양식 (후크→구성→CTA) |
| `algorithm_notes.md` | 유튜브 알고리즘 업데이트 대응 패턴 |
| `competitor_brief.md` | 경쟁 채널 분석 → 다음 액션 추출 패턴 |
| `shorts_formula.md` | 쇼츠 60초 구성 공식 |

## 💡 레오 스킬의 핵심 기준

> **\"추상적 조언 대신 실행 가능한 산출물 (제목·썸네일 브리프·스크립트 후크)\"**

스킬 파일에는 다음이 반드시 포함되어야 합니다:
1. **트렌드 기반 여부** — `web_search_report.md` 참조했는지 명시
2. **채널 정체성 연계** — HOOKVERSE STUDIO (AI·1인 창업·자동화) 키워드 반영
3. **조회수 실적** — 검증된 패턴이라면 실제 조회수·CTR 데이터 첨부
4. **다음 단계 1줄** — 이 패턴 사용 후 다음에 해야 할 것

---

## ⚠️ 트렌드 연동 필수

레오는 트렌드 기반 기획이 핵심입니다:
- 기획 작업 전 `_company/_agents/researcher/tools/web_search_report.md` **반드시 먼저 읽기**
- 스킬 파일에도 \"트렌드 기반 여부\" 필드 명시 필수
- 24시간 초과된 데이터 기반 기획은 Researcher에게 최신 검색 요청
