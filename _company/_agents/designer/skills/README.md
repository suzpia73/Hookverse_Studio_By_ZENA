## 📌 어떤 스킬을 여기에 담나요?

Designer 에이전트는 **브랜드 시각화·썸네일·템플릿** 전문가입니다. 다음 유형의 패턴을 저장하세요:

| 파일명 | 담을 내용 |
|---|---|
| `brand_system.md` | 컬러 팔레트(HEX), 폰트, 로고 사용 규칙 |
| `thumbnail_formula.md` | 클릭률 높은 썸네일 레이아웃 패턴 (검증됨) |
| `design_brief_template.md` | 디자인 의뢰 브리프 작성 표준 양식 |
| `canva_shortcuts.md` | Canva/Figma 반복 작업 단축 워크플로우 |
| `visual_reference.md` | 레퍼런스 채널·계정 모음 + 분석 포인트 |

---

## 💡 Designer 스킬의 핵심 기준

> **\"텍스트 설명만 X — 색상 코드·폰트명·레이아웃 좌표까지 구체적으로\"**

스킬 파일에는 다음이 반드시 포함되어야 합니다:
1. **색상 코드** — `#1A1A2E` 형식으로 명시 (\"진한 남색\" 금지)
2. **폰트 명칭** — \"Pretendard Bold 48px\" 수준으로 구체적으로
3. **레이아웃 설명** — 상하좌우 여백, 배치 비율까지 기록
4. **검증 여부** — 실제 썸네일에 써봤는지 명시

## 어떻게 채우나요?
- 텔레그램에서 `/skill` (직전 산출물 자동 승격)
- VS Code 명령 팔레트: `Connect AI: 방금 산출물 → 스킬로 저장`
- 직접 이 폴더에 `<주제>.md` 파일을 만들어도 됩니다 (`# 제목` + 본문)

`README.md` 자체는 system prompt에 주입되지 않습니다.
