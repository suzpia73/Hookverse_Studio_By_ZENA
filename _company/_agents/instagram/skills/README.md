# 📷 Instagram 스킬 라이브러리

_재사용 가능한 패턴 모음. `memory.md`는 모든 활동의 로그(append-only firehose),
이 폴더는 **검증된 패턴만 골라낸 것**입니다. 각 `*.md` 파일은 다음 호출 시
Instagram 에이전트의 system prompt에 자동 주입됩니다._

---

## 📌 어떤 스킬을 여기에 담나요?

Instagram 에이전트는 **릴스 기획·캡션·해시태그·피드 전략** 전문가입니다. 다음 유형의 패턴을 저장하세요:

| 파일명 | 담을 내용 |
|---|---|
| `reels_hook_pattern.md` | 릴스 첫 3초 후크 공식 (검증된 패턴) |
| `caption_formula.md` | 캡션 구조 (훅→본문→CTA) 템플릿 |
| `hashtag_sets.md` | 카테고리별 검증 해시태그 세트 (10~15개) |
| `posting_schedule.md` | 최적 게시 시간대 + 요일별 콘텐츠 유형 |
| `feed_aesthetic.md` | 피드 톤앤매너 규칙 (색감·필터·비율) |
| `story_sequence.md` | 스토리 연속 기획 패턴 (후속 유도) |

---

## 💡 Instagram 스킬의 핵심 기준

> **\"매 산출물마다 게시 시간 + 후속 스토리 아이디어 1개\"**

스킬 파일에는 다음이 반드시 포함되어야 합니다:
1. **실제 사용한 캡션/해시태그** — 이론 말고 실전에서 쓴 것
2. **도달/저장/댓글 수 기록** — 어떤 포맷이 효과 있었는지 근거
3. **HOOKVERSE STUDIO 채널 정체성 반영** — AI·1인 창업·자동화 키워드 연계
4. **타깃 명시** — 어떤 팔로워층을 타깃으로 한 패턴인지

---

## 어떻게 채우나요?
- 텔레그램에서 `/skill` (직전 산출물 자동 승격)
- VS Code 명령 팔레트: `Connect AI: 방금 산출물 → 스킬로 저장`
- 직접 이 폴더에 `<주제>.md` 파일을 만들어도 됩니다 (`# 제목` + 본문)

`README.md` 자체는 system prompt에 주입되지 않습니다.
