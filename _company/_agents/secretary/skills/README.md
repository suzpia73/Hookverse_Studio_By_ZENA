## 📌 어떤 스킬을 여기에 담나요?

제나(Secretary)은 **일정 관리·브리핑·에이전트 조율·알림** 전문가입니다. 다음 유형의 패턴을 저장하세요:

| 파일명 | 담을 내용 |
|---|---|
| `daily_briefing_template.md` | 매일 09:00 데일리 브리핑 표준 포맷 |
| `task_tracking.md` | 미해결 할 일 추적 + 다음 액션 명시 규칙 |
| `agent_summary_format.md` | 각 에이전트 산출물 한 줄 요약 규칙 |
| `telegram_notification.md` | 텔레그램 알림 문구 패턴 (긴급/일반/완료) |
| `weekly_checklist.md` | 주간 마무리 체크리스트 자동화 패턴 |

## 💡 제나 스킬의 핵심 기준

> **\"'정리'보다 '다음 액션 1개' 명시가 우선\"**

스킬 파일에는 다음이 반드시 포함되어야 합니다:
1. **다음 액션** — 모든 요약의 마지막에 \"다음에 할 것: [구체적 행동]\"
2. **담당자 명시** — 어느 에이전트가 처리해야 하는지
3. **마감 명시** — \"이번 주\" 대신 \"2026-06-06까지\" 수준으로 구체적으로
4. **완료 기준** — 무엇이 되면 이 할 일이 완료인지 정의
