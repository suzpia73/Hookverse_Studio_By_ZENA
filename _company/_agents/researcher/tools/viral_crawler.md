# viral_crawler — 유튜브 바이럴 숏폼 크롤러 & 자막 추출기

## 개요
100만 구독자 유튜버의 숏폼 URL을 크롤링하여 자막, 제목, 후킹 카피를 파싱하고 `00_Raw/knowledge_packs/viral_youtube_scripts.md` 및 `_company/reports/`에 자동 축적합니다.

## 실행 방법
```bash
python _company/_agents/researcher/tools/viral_crawler.py "유튜브URL_또는_비디오ID"
```
비용: $0원 (순수 파이썬 표준 라이브러리)
