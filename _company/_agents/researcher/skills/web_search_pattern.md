# 🔍 웹검색 패턴 — Researcher 검증 패턴

_이 파일은 영숙(Researcher) 에이전트의 system prompt에 자동 주입됩니다._

## 유튜브 채널 방향 조사 시 검색 패턴

### 추천 검색어 조합
```
# 트렌드 파악
"유튜브 쇼츠 트렌드 2026"
"YouTube Shorts trending 2026 Korea"
"AI 콘텐츠 크리에이터 전략"

# 경쟁 분석
"유튜브 구독자 10만 달성 방법"
"유튜브 알고리즘 2026 변화"

# 수익화
"유튜브 수익화 조건 2026"
"유튜브 쇼츠 수익 얼마"
```

### 검색 결과 분석 프레임워크
1. **제목 패턴**: 어떤 제목이 클릭률 높은가?
2. **길이 패턴**: 쇼츠 vs 롱폼 어느 쪽이 성장 중?
3. **주제 패턴**: 지금 뜨는 카테고리는?
4. **채널 패턴**: 성장하는 신생 채널의 공통점은?

### 보고서 작성 시 필수 포함 항목
- 출처 URL 반드시 표기
- 날짜 명시 (실시간 정보임을 강조)
- 불확실한 정보는 "추정" 표기
- 실행 가능한 액션 아이템 3개 이상 포함
