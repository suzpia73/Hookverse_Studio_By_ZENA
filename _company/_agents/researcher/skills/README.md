# 🔍 Researcher 스킬 라이브러리

_재사용 가능한 패턴 모음. `memory.md`는 모든 활동의 로그(append-only firehose),
이 폴더는 **검증된 패턴만 골라낸 것**입니다. 각 `*.md` 파일은 다음 호출 시
Researcher의 system prompt에 자동 주입됩니다._

---

## 📌 어떤 스킬을 여기에 담나요?

Researcher 에이전트는 **트렌드 조사·경쟁사 분석·데이터 수집** 전문가입니다. 다음 유형의 패턴을 저장하세요:

| 파일명 | 담을 내용 |
|---|---|
| `web_search_pattern.md` | 유튜브/인스타 트렌드 조사 최적 검색어 세트 ✅ 활성 |
| `competitor_template.md` | 경쟁사 분석 보고서 표준 양식 |
| `trend_report_format.md` | 월간 트렌드 리포트 작성 포맷 |
| `source_quality.md` | 1차·2차 자료 신뢰도 판별 기준 |
| `keyword_bank.md` | 조사 중 발견한 고효율 키워드 누적 모음 |

---

## 💡 Researcher 스킬의 핵심 기준

> **\"출처 링크 필수, 의견과 사실을 분리 표기 ([사실] / [분석])\"**

스킬 파일에는 다음이 반드시 포함되어야 합니다:
1. **출처 URL** — 링크 없는 정보는 스킬로 승격 금지
2. **날짜 명시** — 언제 조사한 데이터인지 반드시 기록
3. **불확실 표기** — 추정치는 \"[추정]\" 태그 필수
4. **액션 아이템** — 조사 결과에서 도출된 실행 가능한 결론 3개 이상

---

## ⚠️ 반드시 기억할 것

조사 완료 후 `web_search_report.md`에 저장하면 **레오(YouTube)**, **Writer** 에이전트가 자동 활용합니다.
스킬로 저장할 때는 **반복 재사용 가능한 패턴**만 — 일회성 조사 결과는 `memory.md`에!

## 어떻게 채우나요?
- 텔레그램에서 `/skill` (직전 산출물 자동 승격)
- VS Code 명령 팔레트: `Connect AI: 방금 산출물 → 스킬로 저장`
- 직접 이 폴더에 `<주제>.md` 파일을 만들어도 됩니다 (`# 제목` + 본문)

`README.md` 자체는 system prompt에 주입되지 않습니다.
