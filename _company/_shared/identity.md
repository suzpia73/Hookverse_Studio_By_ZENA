# 🏢 회사 정체성

- **회사 이름:** HOOKVERSE STUDIO by KAIRA
- **한 줄 소개:** AI 에이전트 스튜디오를 구축하며 콘텐츠를 만드는 1인 크리에이터입니다.
- **타깃 청중:** '새로운 시선과 상상을 찾는 당신' 을 위한 콘텐츠입니다.
- **브랜드 톤:** 직설적 + 데이터 기반 + 실행 중심 + 친근함
- **금기:** 클리베이트 제목 남용, 정치적 편향 / 사회적 편향 콘테츠, 검증되지 않은 정보, 저품질 자동 생성 콘텐츠, 협오 / 자극 콘텐츠, 청소년 유해 콘텐츠
