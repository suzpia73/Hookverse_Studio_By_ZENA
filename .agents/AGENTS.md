# Hookverse Studio 워크스페이스 규칙

## 새 대화 시작 시 필수 절차
새 대화가 시작되면, 오빠의 질문에 답하기 전에 반드시 아래 파일들을 먼저 읽어라:
1. `C:\Users\june2\.gemini\config\skills\hookverse_system\SKILL.md` — 전체 시스템 연동 역사 및 디버깅 노하우
2. `d:\HOOKVERSE-SYSTEM\HOOKVERSE_STUDIO\_STATUS.md` — 마지막 작업 세션의 진행 상태 및 다음 할 일

이 두 파일을 확인한 뒤, 오빠에게 "이전에 ~까지 했고, 다음은 ~를 해야 해요"라고 짧게 요약해준 다음 작업을 이어가라.

## 작업 중 상태 저장 (필수!)
**중요한 작업을 하나 완료할 때마다** 즉시 `_STATUS.md`를 업데이트하라. 대화가 끝날 때까지 미루지 마라 — 한도 제한이나 연결 끊김으로 저장 기회를 잃을 수 있다. SKILL.md에도 중요한 발견이나 해결책이 있으면 즉시 추가하라.

## 🚪 오빠 외출/퇴근/산책 자동 체크포인트 규칙 (절대 헌법!)
오빠가 *"산책 간다"*, *"내일 보자"*, *"노트북 끈다"*, *"나갔다 올게"*, *"퇴근하자"* 등 휴식/종료 뉘앙스를 말하면, 제나는 즉시:
1. `_STATUS.md` 및 `SKILL.md` 최신화
2. 임시 파일 정리 및 작업 트리 상태 점검
3. `git add -A`, 커밋, `git push origin main` 원격 동기화 자동 완료
4. 깔끔하고 기분 좋은 마중 보고 후 대기 상태로 전환한다.

## 📋 영구 누적 마스터 체크리스트 원칙 (절대 사규!)
`_STATUS.md`의 모든 할 일 목록은 반드시 `- [ ]`(미완료)와 `- [x]`(완료) 체크박스 형식으로 영구 관리한다.
- 미완료된 항목은 절대로 임의로 삭제하거나 생략/압축하지 않고 끝까지 추적 보존한다.
- 완료된 작업만 `- [x]`로 체크하여 완료 아카이브에 기록하고, 새로운 과제는 `- [ ]`로 아래에 계속 덧붙인다.
