## 📌 1. 핵심 상황 요약 (팩트)
*   **증상**: 가상 사무실(Connect AI)에서 CEO 호출 시 `exit status 0xc0000409` (버퍼 오버런) 500 에러가 계속 반복됨.
*   **진짜 원인**: 
    *   오빠 컴퓨터의 그래픽 카드(`GeForce MX250`) 비디오 메모리(VRAM)가 **2GB**로 한정되어 있음.
    *   이 상태에서 5.2GB 크기의 `qwen2.5:7b` 모델을 기동하려다 보니 VRAM 용량 초과로 인해 Ollama가 GPU 가속을 쓰지 못하고 비상용 CPU 백엔드(`llama-server-cpu`)를 강제 가동함.
    *   비상용 CPU 백엔드가 가상 사무실의 복잡한 JSON 제약 조건(response_format)을 해석하려다가 연산 분할 한계(`GGML_SCHED_MAX_SPLIT_INPUTS`)를 초과하면서 C++ 엔진 내부 Assertion 실패로 즉사했던 것임.
*   **해결책**:
    *   터미널에서 `ollama rm`을 통해 쓰지 않는 대용량 찌꺼기 모델(`hookverse:7b`, `qwen2.5-7b-safe`)을 삭제해 메모리를 확보함.
    *   VRAM 2GB 환경에서도 완벽히 GPU 가속을 받으며 원활하게 구동되는 **`gemma2:2b`** (1.6GB) 모델로 에이전트 구동 엔진을 일괄 변경함.
    *   터미널에서 `ollama run gemma2:2b` 명령어로 정상 대답(GPU 가속 구동)을 팩트 체크 완료함.
