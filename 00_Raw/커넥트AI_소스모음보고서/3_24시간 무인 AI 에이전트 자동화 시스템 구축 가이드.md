### 1\. 최종 목표 및 결과물 (WHAT)

**최종 시스템의 정체 및 비즈니스 목표**이 채널이 구축하고자 하는 최종 시스템은 대본 기획, 이미지/영상 프롬프트 작성, 리서치, 그리고 유튜브 업로드까지 1인 운영 규모의 모든 파이프라인을 24시간 자동으로 처리하는 '무인 콘텐츠/마케팅 AI 에이전트 생태계'입니다 1-3.

**무료 한도만으로 지속 운영 가능 여부결론적으로 클라우드 API(Gemini API 등)의 무료 한도만으로는 24시간 지속 운영이 불가능합니다.**강의에서는 대본 생성, 리서치 등 24시간 백그라운드에서 구동되어야 하는 파이프라인을 클라우드 API에만 의존할 경우 다음과 같은 문제로 지속 운영이 불가능하다고 명확히 진단하고 있습니다.

* 무료 버전을 계속 호출하면 단시간 내에 "코타(Quota)가 다 꽉 찼다"는 에러가 발생하며 파이프라인이 중단됩니다 4\.  
* 토큰 한도가 존재하여 무인으로 계속 쓰다 보면 금방 소진되어 "일주일 동안 기다려야 하는" 셧다운 상황이 발생합니다 5\.  
* 이에 대한 궁극적인 해결책(결과물)으로, API 종량제 요금 및 토큰 소진을 '0원'으로 수렴시키기 위해 오프라인 기반의 로컬 AI(Gemma 4 등)를 주축으로 연동하는 하이브리드 파이프라인 구축을 최종 목표로 삼고 있습니다 6-8.

### 2\. 구축 방법 및 실행 절차 (HOW)

**API 한도 제약을 다루는 워크플로우 및 실행 절차**시스템 구축 시 무료 한도와 과금 제약을 극복하기 위해 다음과 같은 단계별 메커니즘을 사용합니다.

1. **초기 세팅 및 무료 크레딧 소진**: 파이프라인의 최초 구축 및 검증 단계에서는 구글 클라우드 신규 가입 시 제공되는 약 300달러(약 40만 원)의 무료 크레딧을 사용하여 Gemini API 키를 발급받고 에이전트 기능 테스트를 진행합니다 9-11.  
2. **한도 초과(Quota Error) 시 임시 우회**: 영상 및 이미지 생성 파이프라인 테스트 중 일일 생성 한도(Quota)가 초과되어 작업이 막히면, "구글 아이디를 하나 더 만들어서 시도"하는 임시 우회 절차를 취합니다 12\.  
3. **한도 극복을 위한 로컬 AI 데이터 플로우 분리 (최종 메커니즘)**: 24시간 작동해야 하는 '대본 작성, 리서치 파싱, 에이전트 간 업무 지시 및 협업 대화'는 철저하게 오프라인 로컬 머신(LM Studio/Ollama)에서 구동되는 로컬 AI로 라우팅하여 토큰 소모를 원천 차단합니다 13-15.  
4. **클라우드 도구의 제한적 호출**: 최종 고품질 에셋(예: 8초 길이의 상업용 영상이나 특정 고화질 제품 이미지)이 필요할 때만 제한적으로 Google OPAL이나 Google Flow 등의 무료 클라우드 생성 도구를 호출하여 전체 파이프라인을 멈춤 없이 순환시킵니다 16-19.

### 3\. 사용된 전체 프로그램 및 툴 스택 (TOOLS & TECH STACK)

**핵심 API 및 클라우드 서비스**

* **Google AI Studio (Gemini API)**: 대본 기획, 딥 리서치, 복잡한 JSON 프롬프트 구조화 등의 추론 영역에 사용됨. 강력하지만 무료 한도 초과 시 작동이 멈추는 제약이 있음 4, 20, 21\.  
* **Google OPAL**: 영상 생성 에이전트를 자동화하는 클라우드 워크플로우 도구. Veo 3.1 모델을 연동해 영상을 무료로 생성할 수 있는 플랫폼 역할을 함 22, 23\.  
* **Google Flow**: Nano Banana 2 모델을 사용하여 이미지를 자동 생성할 때 크레딧 소모 없이(0 크레딧) 구동할 수 있도록 해주는 실험실 툴 16, 24\.

**무료/무제한 파이프라인 구축을 위한 로컬 툴 스택**

* **LM Studio / Ollama**: 클라우드 API 호출 한도의 종속성에서 벗어나, 24시간 오프라인 상태에서도 에이전트가 텍스트를 생성하도록 구동해 주는 로컬 AI 서버 프로그램 8, 25, 26\.  
* **Gemma 4 (E2B, E4B) / Qwen 등**: LM Studio 및 Ollama 내부에서 가동되는 핵심 오픈소스 AI 모델. API 한도 제약이나 요금 없이 무제한으로 파이프라인의 백그라운드 대화/코딩 텍스트를 생성함 27, 28\.

### 4\. 핵심 소스 코드 및 설정 지침 (CODE & CONFIG)

**1\. Gemini API 무료 티어 사용량 한도 (RPM, TPM, 일일 요청 수)**

* RPM (분당 요청 수): **소스에 명시 안 됨**  
* TPM (분당 토큰 수): **소스에 명시 안 됨**  
* 일일 텍스트/API 요청 수: **소스에 명시 안 됨***(※ 강의 소스 내에서는 API 토큰 한도 초과로 "일주일 기다려야 한다"거나 "코타가 꽉 찼다"는 증상만 언급될 뿐, Google AI Studio 무료 티어의 정확한 RPM, TPM, 일일 API 콜 횟수 수치는 명시되어 있지 않습니다).*

**2\. 영상 및 이미지 생성 관련 무료 한도 설정값**

* **Google Cloud 신규 가입 무료 크레딧**: 300달러 (약 40만 원) 10, 11\.  
* **Veo 3.1 (Google OPAL 구동 시) 영상 생성 일일 한도**: 8초 분량 영상 기준 하루 약 15개 22, 29\.  
* **Nano Banana 2 (Google Flow 구동 시) 이미지 생성 비용**: 동시 4장 생성 시 0 크레딧 차감 (완전 무료) 16, 30\.

**3\. API 과금 및 탈취 방지를 위한 보안 설정 지침**

* 자동화 파이프라인 소스 코드 내에 API 키를 하드코딩하는 것을 엄격히 금지합니다.  
* **설정 지침**: 프로젝트 최상위 루트 디렉토리에 숨김 파일로 .env를 생성하고, 내부에 GEMINI\_API\_KEY="..." **텍스트 확인 불가 \- 보안 마스킹** 형태로 저장하여 해커의 무단 과금 공격(API 키 탈취)을 방지하도록 설정합니다 4, 31\.

**4\. 텍스트 파이프라인 토큰 최적화 지침 (antigravity\_config.json 등)**

* 로컬 호스트를 호출하는 @local 명령어 지침을 세팅하여, 일상적인 대본 작성이나 1차 코딩은 로컬 모델(Gemma 4)로 처리해 API 토큰 소비를 0으로 강제합니다.  
* 더 높은 창의성이나 고도화된 오류 디버깅이 필요할 때만 제한적으로 Gemini/Claude API를 호출하는 식의 '선(先) 로컬 \- 후(後) 클라우드' 라우팅 프롬프트 지침을 설정하여 한도를 관리합니다 14, 15, 18\.
