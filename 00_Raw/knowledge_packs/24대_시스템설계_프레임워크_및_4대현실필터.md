# 🏛️ AI 에이전트 1인 기업 24대 시스템 설계 프레임워크 & 4대 현실 필터

> **기반**: 오빠 ❌ GPT뉴라 20대 설계 원형 + 부회장 제나의 실전 엔지니어링 보강 (24대 완성본)  
> **목적**: Hookverse Studio의 10대 에이전트 완전 자립 및 1인 무인 기업 구축 총괄 아키텍처

---

## 🧭 1. 오빠와 GPT뉴라의 8대 핵심축 (The 8 Core Pillars)
1. **[1축] 목표 / KPI**: 시청 유지율 80%+, 110%+ 루프 시청, OSMU 수익화 달성
2. **[2축] 요구사항 (Requirements)**: 오빠의 11대 자동화 요구사항 (트렌드 ➡️ 제작 ➡️ 업로드 무인화)
3. **[3축] 로드맵**: 30초 숏폼(1단계) ➡️ 롱폼(2단계) ➡️ 웹소설/웹툰(3단계) ➡️ 자체 OST/굿즈(4단계)
4. **[4축] 아키텍처**: NVIDIA MX250 2GB VRAM 로컬 $0원 모델(`gemma2-safe`) + Antigravity V2 클린 환경
5. **[5축] 워크플로우**: 하루 10~12시간 집중 온디맨드 단일 미션 릴레이 (24시간 발열 방지)
6. **[6축] 파이프라인**: [소싱 ➡️ 매칭 ➡️ 대본 ➡️ 5~8초 영상화 ➡️ 조립] 무인 컨베이어 벨트
7. **[7축] 에이전트 설계**: 10대 팀원 R&R 분담, 첫 글자 강제 락(`Strict Output Rule`), 언어 격벽 락
8. **[8축] 도구 / API 연결**: 6대 외부 연동망 ALL GREEN 및 실전 파이썬 도구 3종 탑재

## 🚦 3. 제나의 4대 현실성 검증 필터 (Reality Filters)

- 🟢 **현재 기술로 즉시 가능한 것**:
  - 실시간 트렌드 크롤링, 5-in-1 바이럴 대본 산출, 뉴라 앵커락 실사 프롬프트, 15분 관제, 6대 API 연동.
- 🟡 **추가 개발로 완성 중인 것**:
  - 5~8초 영상화(Motion Video) 툴 연동, edge-tts 음성 합성 및 자막 결합 무인 렌더링.
- 🔴 **완전 자동화하면 위험한 것 (금지 구역)**:
  - 무검수 유튜브 자동 공개 업로드 (알고리즘 밴 위험), 무제한 자동 결제 집행 (금전 사고 위험).
- ✋ **사람(오빠)이 반드시 최종 승인해야 할 것 (Human-in-the-Loop)**:
  - 최종 3부작 대본 승인, 썸네일 셀렉트, 최종 유튜브 발행 버튼 클릭.
