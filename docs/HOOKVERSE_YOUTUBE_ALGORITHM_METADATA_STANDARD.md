## Ⅰ. 오빠의 4대 핵심 사규 (절대 준수 기준)

1. **채널명 태그 영구 배제**:
   - 신생 채널명(`Hookverse`, `훅버스스튜디오`, `NEURA` 등)은 시청자가 검색창에 칠 일이 0%이므로 태그나 검색어에 절대 넣지 않는다. (알고리즘 낭비 원천 차단)
2. **영어 단어 억지 남발 금지**:
   - 한국 시청자가 굳이 영문으로 검색할 일이 없는 단어는 배제한다.
   - 단, 글로벌 쇼츠 피드 분류에 공식적으로 쓰이는 `#Shorts` 및 대중적 고유명사 외에는 자연스러운 한국어를 기본으로 한다.
3. **소품/배경 명칭 태그 금지**:
   - 시청자는 `공중전화`, `지하금고`, `스마트폰` 같은 소품 단어를 검색창에 치지 않는다.
   - 오직 대중이 실제로 검색하는 **핵심 장르·테마 단어 5~7개**만 정밀하게 넣는다.
4. **제목 스포일러 0% + 상황 훅 원칙**:
   - 결말 반전 대사를 제목에 다 까발리지 않는다.
   - **"긴박한 상황 선언" + "수화기 너머의 한마디(궁금증 공백)"** 형태로 시청 유지율을 극대화한다.
